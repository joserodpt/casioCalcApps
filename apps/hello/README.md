# Hello

Starter add-in for the fx-CG50 (colour) and the fx-9860G II (black and white), built with fxSDK + gint.

## Download

| Calculator | File |
|---|---|
| fx-CG50, fx-CG10, fx-CG20 (colour) | [Hello.g3a](../../dist/g3a/Hello.g3a) |
| fx-9860G II, fx-9750G II, Graph 35+E II (black and white) | [Hello.g1a](../../dist/g1a/Hello.g1a) |

Copy the file to the root of the calculator's storage over USB (USB Flash mode, F1), then eject it; the app appears in the MENU.
