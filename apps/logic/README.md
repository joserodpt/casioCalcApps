Truth table and Karnaugh map for the Casio FX CG 50 (works with the CG10 and 20 too). Made with fxSDK and gint.

Enter a Boolean expression of up to four variables (A, B, C, D) and get its
truth table, a coloured Karnaugh map with the groupings outlined, and the
simplified sum-of-products (via prime-implicant cover). You can also tick
minterms directly in the truth table. Switch views with F1–F3.

## Expression (F1 / EDIT)

| Key | Action |
|---|---|
| F4 F5 F6 | Insert A, B, C |
| X,θ,T / log / ln / sin | Insert A, B, C, D |
| + | OR (also `\|`) |
| × | AND (also `.`; `AB` means A AND B) |
| ^ | XOR |
| ÷ | NOT (prefix `!`; postfix `'` also works, as in `A'`) |
| ( ) | Parentheses |
| ◀ ▶ | Move the cursor |
| DEL / AC | Delete / clear |

## Truth table (F2)

| Key | Action |
|---|---|
| ▲ ▼ | Select a row |
| EXE | Toggle the output (switches to minterm mode) |
| F5 / F6 | Add / remove a variable |

## Karnaugh map (F3)

Each prime implicant in the cover is outlined in its own colour and listed,
with the simplified expression along the bottom.

OPTN opens the info screen and EXIT quits.
